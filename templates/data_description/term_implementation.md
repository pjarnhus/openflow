### Term Implementation
The Term Implementations are a list of established terms for the project.
They embody a shared vocabulary and must be used verbatim.
The Terms are supplied by the user along with their definition in the form

```
## <Term>
implementation: <Term Implementation>
aliases: <Comma-separated list of known aliases for the Term>
related terms: <Comma-separated list of related Terms>
```
If no Terms have been defined for the project, the user will write "No Terms defined."
