### User Stories
The User Stories are markdown files produced by the User Story Agent, about the project's functional requirements.
Each story is phrased from an end user's perspective and must be addressed by its story number.
The User Stories are supplied to the user in the form

```
## User story: user_story_<N>.md
# User Story <N>

As a [Persona]
I want to [goal] so that [benefit]

## Acceptance Criteria:

- [Criterion 1]
- [Criterion 2]
- [Criterion 3]
```
The stories appear in ascending numerical order of their filenames.
If no User Stories have been written for the project, the user will write "No user stories found".
